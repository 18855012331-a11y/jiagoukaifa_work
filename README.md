# 太阳系行星数据

纯 HTML 课堂作业。直接用浏览器打开 `index.html`，无需安装依赖。也可在本目录运行 `python3 -m http.server 8000`，再通过本地浏览器访问该服务。

- 主表用行、单元格组织八大行星数据，包含 `rowspan` 分类、`colspan` 参数分组。
- 主表 `border="2"`，说明表 `border="1"`。这些传统 HTML 属性仅为满足本次作业；没有引入 CSS、JavaScript、字体或颜色样式。
- 行星名称链接到 NASA 介绍页；八张原创 SVG 示意图保存在 `images/`，以相对路径引用，不依赖在线图片。
- 数据为 NASA 行星数据表中常见的教学近似值，采用赤道直径和恒星自转周期。参考站点在制作时返回 HTTP 403，未能核对当前版本；不声称这些值是最新数据。
- 图片仅作辨认示意，并非天文照片，也不表示真实比例。

题目附件为 CSS 布局课件，未显示行星表，因此本页依据文字要求组织表格，不声称逐像素还原课堂表格。
