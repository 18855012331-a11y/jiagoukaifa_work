# 第一次作业：HTML 页面结构与 CSS 基础布局

[返回课程作业目录](../README.md)

本目录为《智慧水利平台架构和开发》课程第一次作业，以太阳系行星数据为页面主题。

在原来的行星 HTML 页面上补充外部 CSS，内容继续使用八大行星数据。直接用浏览器打开 `index.html` 即可，无需安装依赖。

## 文件

- `index.html`：原行星表及首页所需结构，保留原有两个表格、全部行星数据、名称链接、合并单元格与相对路径图片。
- `styles.css`：整个页面的外部样式，包含注释说明，没有内联 CSS 或 JavaScript。
- `images/`：原有八张 SVG 行星示意图，均可离线显示。

## CSS 作业要求

1. **课堂思考**（页面 `#thinking`）：垂直居中、均分主轴空间、同一行列等高的答案、代码与示例；说明 `flex-direction`、可用高度和最小尺寸的影响。
2. **酷炫盒子**（`#cool-box` / CSS `.cool-box`）：200×72px，Flex 双向居中；根字号 16px，1.125rem = 18px；同色系背景与文字、黑色文字阴影、圆角、1px 深色实线边框；右下渐变在 0% 完全透明、30% 达到 0.2 并保持到 100%；普通外阴影与两个方向相反的 inset 内阴影；支持悬停和键盘聚焦。
3. **首页结构**（`#top` 和 `#planet-data`）：参照课程首页的结构要求，为行星页增加导航、头部行星大图区域、统计、选项卡与正文。选项卡分别展示原行星参数表、数据说明表和行星图鉴。使用原生单选按钮配合 CSS，鼠标和键盘均可切换。
4. **四个布局练习**（`#layouts`）：Flex 垂直堆叠、定位叠加、Flex 换行（One 通栏，Two/Three 并排，Four 通栏）和行星图片瀑布流（多列布局，卡片下方附标签）。

智慧水利课程首页仅作为布局结构参考，页面主题仍是太阳系行星；未提供参考样图，因此不声称精确还原样图。

## 数据与图片

- 表格继续保留 `rowspan`、`colspan` 和原来的 `border` 属性，具体视觉样式由 CSS 定义。窄屏只在表格容器内横向滚动。
- 行星名称与图鉴链接指向 NASA；数据采用常见教学近似值、赤道直径和恒星自转周期。参考站点此前返回 HTTP 403，未核对其最新数据。
- 图片是原有本地示意图，不是天文照片。头图中的行星位置、距离、轨道与大小均不按真实比例。
- 没有在线字体、图片或脚本依赖。浏览器默认 16px 根字号下，盒子文字为 18px。

也可在本目录运行 `python3 -m http.server 8000`，通过本地服务查看。
