02 / THINKING

三个问题，认识 Flex

理解布局的轴与空间
01

让内容垂直居中

默认主轴水平时，使用 align-items: center 沿垂直的交叉轴对齐；父容器需要有可用高度。

我在正中间
.parent {
  display: flex;
  min-height: 120px;
  align-items: center;
  justify-content: center;
}

如果主轴改为 column，垂直居中应使用 justify-content: center。

02

所有子项均分空间

给子项设置 flex: 1，从零基础尺寸均分主轴空间；清除最小尺寸限制，避免长内容撑开子项。

OneTwoThree
.parent { display: flex; }
.child {
  flex: 1 1 0;
  min-width: 0;
  overflow-wrap: anywhere;
}

均分高度时，父容器设定高度和 flex-direction: column，子项使用 min-height: 0，必要时设置 overflow: auto。

03

不同内容，列高相同

同一行中使用 align-items: stretch；子项保持自动高度，就能跟随内容最多的列一起伸展。

短内容这一列的
内容更多，
但列高一致。另一列
.parent {
  display: flex;
  align-items: stretch;
}
.child {
  flex: 1;
}

这是同一 Flex 行内的等高；如果换成多行，每行分别计算高度。

由内到外，叠出层次

  1. 尺寸与文字宽 200px、高 72px，Flex 双向居中。根字号 16px，1.125rem × 16px = 18px。
  2. 颜色与边框青蓝底色、同色系浅色文字和黑色文字阴影；1px 深青色实线边框，圆角 14px。
